# nixos-config 학습 문서

이 저장소(dustinlyons/nixos-config 기반, macOS/nix-darwin 중심)를 이해하고 운영하기 위해
정리한 학습 노트 모음입니다.

Nix의 동작 원리, 이 저장소의 구조, flake, macOS 설정 관리의 범위와 한계,
최초 셋업에서 겪는 함정, 자주 쓰는 명령어 등을 다룹니다.

## 보는 법

이 디렉토리(`docs/`)의 문서들을 직접 살펴보세요. 파일 이름 앞 번호는 대략적인 읽기 순서입니다.
`research/`에는 인덱스에 묶지 않은 자유 형식의 분석 글이 들어 있습니다.

## 한 줄 요약

설정을 "데이터"로 빌드해 `/nix/store`에 박제하고, 라이브 시스템이 그 데이터에 수렴하도록 "활성화"한다.
패키지든 `/etc`든 dock이든 전부 같은 원리. macOS에서는 Apple이 스크립트로 열어둔 표면까지만 닿을 수 있다.
