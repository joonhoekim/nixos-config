# OS 지원 기록

이 설정이 어느 시점에 어느 OS 에서 동작했는지의 기록이다. 한 행은
**그 날짜에 그 OS·기종·커밋 조합에서 `apps/check/mac` 이 깨진 것 없이 통과했다**는
뜻이다. 통과하지 않은 조합이나 점검하지 않은 조합은 적지 않는다.

행은 손으로 쓰지 않는다. `./apps/check/mac --record` 가 다음 조건을 모두 만족할 때만
끝에 한 행을 붙인다.

- 깨진 것(✗)이 0개
- 활성화된 세대가 체크아웃과 같다 — 적힌 커밋이 실제로 검사한 설정이어야 한다
- 작업 트리가 깨끗하다

같은 호출이 `local/snapshot/` 에 상태 스냅숏도 한 벌 남긴다. 거기에는 계정명·경로·
설치한 앱 목록이 그대로 들어 있어서 `.gitignore` 로 빼 두었다. 이 파일은 공개해도
되는 요약만 갖는다.

메이저 업그레이드 절차는 [03-operating-on-macos.md](03-operating-on-macos.md) §2 의
"메이저 업그레이드 전후 점검".
