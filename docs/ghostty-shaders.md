# ghostty 셰이더 — crt.glsl 과 glow.glsl

ghostty 는 이 저장소의 기본 터미널이고, `custom-shader` 로 셰이더토이 규약(mainImage / iChannel0 / iResolution)의 GLSL
셰이더를 터미널 화면에 덮을 수 있다. 셰이더는 `modules/shared/ghostty/shaders/` 에 있고 NixOS·macOS 가 같이 쓴다. 룩을
고르는 방법과 조각 표는 `modules/shared/ghostty/README.md`, 전환 스크립트는 `apps/rice/term`
([rice-tools.md](rice-tools.md#터미널-룩--appsriceterm)). 하이프랜드 화면 셰이더 crt/crt.frag 는 이 crt.glsl 에서
옮긴 것이다([hyprland-shaders.md](hyprland-shaders.md#crtcrtfrag)).

값은 전부 `#define` 에 모여 있고 `// @a..b` 꼬리는 `apps/rice/knobs` 가 읽는 손잡이 범위다.

## crt.glsl 이 원본(space_dots)과 다른 곳

원본: Maxim Samoliuk 의 Hyprland 화면 셰이더(MIT, `_temp/ricing-examples/space_dots/.other/orig.frag`). 터미널용으로
다시 짰다. 목표는 완벽 재현이 아니라 감성이라, 진짜 CRT 에 있는 것이라도 결이 거친 것은 약하게 두거나 지운다 — 눈이
"흉내"라고 느끼는 지점은 대개 세기가 아니라 결이 거친 데서 온다.

| | 원본 | crt.glsl |
|---|---|---|
| 블룸 | 24방향 × 4단계 = 픽셀당 96탭(원본 activate.sh 가 패널을 1024x768 로 떨어뜨려야 감당) | 골든앵글 나선 16탭 + 가우시안 가중. 링으로 돌면 밝은 글자 둘레에 방향 수만큼 별 모양 결이 남고 나선은 안 남는다 |
| 그레인 | 픽셀마다 새 백색 잡음 — 모래처럼 보이고 주사율이 곧 속도 | 격자에서 뽑아 보간한 값 노이즈를 초당 GRAIN_HZ 번 갱신, 사이를 smoothstep 으로 잇는다 |
| 깜빡임 | `sin(60.0 * time)` — 주사율을 상수로 박아야 하고 틀리면 밝기가 널뛴다(원본 주석의 경고) | 천천히 굴러 내려가는 험 바, 주사율 무관 |
| 색수차 | 화면 전체 고정폭 | 가운데 0, 가장자리로 갈수록 벌어진다(실제 전자총 정렬 오차와 같고 본문이 덜 흐려진다) |
| 가장자리 | 곡률 바깥을 if 로 잘라 곡선이 계단 | EDGE_SOFT(1.5 픽셀)에 걸쳐 부드럽게 죽인다. 덤으로 fwidth 를 쓰는 stripes 가 분기 밖에 있어 미분값이 정의된다 |

## 그레인 — 크기와 갱신 빈도

GRAIN(세기), GRAIN_PX(덩어리 크기), GRAIN_HZ(초당 새 무늬)를 고를 때 함정이 둘이고 방향이 반대다.

- 덩어리가 크면 잡음 에너지가 저주파로 몰려 넓은 면적이 같이 밝아졌다 어두워지고, 눈은 질감이 아니라 "화면이 깜박인다"로
  읽는다(2.5px 에서 이 증상).
- 덩어리가 작으면 픽셀 단위 백색 잡음이 되어 지글거린다.

그래서 크기로 줄타기하지 않고 `grainAt()` 이 하이패스를 한다: 잔 노이즈에서 네 배 굵은 노이즈를 빼면 넓은 면적의 평균이
0 에 수렴해, 세기를 올려도 깜박임으로 번지지 않는다. GRAIN_PX 는 질감만 정한다.

GRAIN_HZ 를 높게(24 가 아니라 40~60 대) 두는 것도 같은 이유다. 저주파를 걷어낸 뒤에는 빠른 쪽이 필름 그레인에 가깝고,
사람이 깜박임에 가장 민감한 3~15Hz 대역을 벗어난다. 실제 갱신 빈도는 GRAIN_HZ × ANIM_SPEED.

새 무늬로 툭 갈아치우면 그게 지글거림이 되므로 계단 사이를 smoothstep 으로 잇는다.

## 더하기와 곱하기 (modulate, GRAIN_ADD/GRAIN_MUL, HUM_LIFT)

배경이 순검정인 터미널에서 효과를 얹는 방법은 한쪽만 쓰면 반드시 한쪽에서 안 보인다.

- 곱하기: 검정 × 무엇이든 검정이라 어두운 곳에서 죽는다. 띠 안에서 화면을 6% 밝게 해도 검정 × 1.06 은 검정이다.
- 더하기: 같은 절대량이라도 바탕이 밝을수록 상대 대비가 작고 감마가 어두운 쪽 차이를 한 번 더 키운다. 검정 배경에서
  0 → 0.075 는 대비가 무한대지만 흰 글자 위의 1.0 → 1.075 는 안 보인다 — 코드상 글자 위에 더해도 잡티가 "글자 뒤에
  깔린" 것처럼 보인다.

그래서 `modulate(col, amount, gain, lift) = col * (1 + amount*gain) + amount*lift` 로 둘을 섞는다. gain 은 밝은 픽셀의 몫,
lift 는 검정의 몫. 그레인은 GRAIN_MUL/GRAIN_ADD, 험 바는 HUM/HUM_LIFT 로 얹는다. GRAIN_MUL 을 0 으로 두면 잡티가 배경에만
깔린다.

## 험 바

전원 주파수와 수직 주사가 어긋나서 생기는 밝기 띠.

- 화면 높이를 한 주기로 하는 사인을 전체에 곱하면 어느 순간에도 화면 전부가 밝기 변화 중이라 "화면이 깜박인다"로 읽힌다.
- 글로우에만 걸면 검정 배경이 대부분인 터미널에서는 글로우가 글자 둘레에만 있어 안 보인다.
- 그래서 좁은 띠 하나(HUM_WIDTH, 화면 높이 비율)가 천천히 굴러 내려간다. 진짜 브라운관에서 보이는 모양이고, 국소적이라
  눈이 "화면이 변한다"가 아니라 "무언가가 지나간다"로 읽어 세기를 올려도 덜 피곤하다. 띠 밖은 humBar 가 0 이라 화면
  대부분은 손대지 않는다.
- 순검정에서는 곱하기가 아무것도 못 하므로 띠를 보이게 하는 값은 HUM_LIFT(검정을 들어 올리는 양)다. HUM 과 HUM_GLOW 는
  그 위의 장식이고, 띠가 지날 때 글자 둘레가 확 번지는 게 실제로 눈에 띄는 부분이라 글로우 쪽(HUM_GLOW)을 훨씬 세게 민다.
- 위치는 fract 로 감고, 감긴 좌표에서의 최단 거리로 띠를 만든다. 한 바퀴 시간은 1 / (HUM_SPEED × ANIM_SPEED) 초.

## 커서 꼬리, 포커스, 알파, 스캔라인

- **꼬리 거리장**은 커서 반폭/반높이로 나눈 공간에서 잰다. d 의 단위가 "커서 몇 개분"이 되어 꼬리가 커서와 같은 두께·비율로
  끌린다. min(폭,높이) 반경 하나로 재면 블록 커서(가로 짧고 세로 긴)에서 가로폭에 맞춘 가느다란 지렁이가 나온다.
- `if (TRAIL * fade * moved <= 0.0) return` 은 조건이 유니폼만으로 정해져 화면 전체가 같은 쪽으로 분기하므로 워프가 갈라지지
  않는다. 커서가 멈춰 있으면 TRAIL_SEC(0.22초) 뒤부터 늘 여기로 빠져 거리장 계산을 건너뛴다.
- 꼬리 fade 는 (1-age)^2 — 인광체가 지수적으로 꺼지는 것과 비슷하게 빨리 죽는다.
- **포커스**: `custom-shader-animation = true` 는 포커스된 창만 루프를 돈다는 뜻이지 다른 창을 절대 안 그린다는 뜻이
  아니다. 수정키 입력·링크 호버로 가끔 한 장씩 그려지고, 그때 iTime 만 뛴 채라 움직이는 것들이 느리게 뚝뚝 넘어가 보인다.
  ghostty 가 iFocus 를 주는 이유가 이것이다(문서의 "deceptive frames"). 포커스가 없으면 시간을 세우고 띠를 지운다 —
  그레인은 고정된 씨앗으로 남아 질감은 그대로다.
- **알파**: 곡률 안쪽에서만 터미널 알파를 따라가야 background-opacity 가 산다(glow 와 같은 규칙). 바깥은 셰이더가 검정으로
  죽인 자리라 같이 투명해지면 유리 안쪽이 아니라 창에 뚫린 구멍으로 보이므로 1 로 못 박는다 — 불투명한 검정이 곧 브라운관
  베젤이다. crt.conf 의 background-opacity(0.9)가 다른 룩(0.94)보다 낮은 건 곡률·스캔라인·그릴이 화면을 어둡게 깎아 같은
  값이면 crt 만 탁해 보여서다.
- **스캔라인** 주기는 픽셀 단위다(HiDPI 에서도 같은 굵기). 3 픽셀이면 한 주기에 표본이 셋뿐이라 곡률이 닿는 곳마다 모아레가
  되므로 4. 한 화면 픽셀에 반 주기 넘게 들어가는 곳(곡률 강한 가장자리)은 표현할 수 없어 줄무늬를 서서히 지운다. 인광체
  그릴은 스캔라인과 겹치면 방충망처럼 보여 얕게(0.07) 둔다.
- **해시**는 Dave Hoskins 계열이다. sin(dot(...)) 해시는 좌표가 커지면 무늬가 반복돼 잡티가 아니라 격자처럼 보인다.

## glow.glsl

crt.glsl 에서 매일 쓸 만한 부분(블룸과 아주 얕은 스캔라인)만 남긴 상시용 룩이다. 곡률·색수차·그릴이 없어 본문 가독성은
그대로다. iTime 을 안 써서 glow.conf 가 custom-shader-animation 을 끈다 — 화면이 바뀔 때만 그린다.

남긴 부분은 crt.glsl 과 같은 방식(골든앵글 나선 16탭 + 소프트 니)이어야 한다. 링 8방향은 밝은 글자 둘레에 별 모양 결을
남기고, 하드 임계값은 글자 굵기에 따라 번짐이 튄다. 두 셰이더는 독립 프로그램이라 코드를 공유할 방법이 없으므로 crt.glsl
을 원본으로 보고 맞춘다. 창을 도려내지 않으므로 알파는 src.a 를 그대로 살린다.
