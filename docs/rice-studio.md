# 라이싱 스튜디오

라이싱 스튜디오는 하이프랜드 화면 셰이더를 고르고 겹치고 값을 맞추는 창이다. Quickshell(QML 로 데스크톱 셸을 짓는
런타임)로 만든 별도 프로그램이고, 소스는 `modules/nixos/hyprland/rice/studio/` 에 있으며 `~/.config/rice-studio` 로
심긴다. 이 문서는 창의 구조와 설계 판단이다. 띄우는 껍데기 `apps/rice/studio` 는 [rice-tools.md](rice-tools.md#라이싱-스튜디오--appsricestudio),
값을 쓰는 스크립트들은 [rice-scripts.md](rice-scripts.md).

## 탭

셰이더(ShaderTab.qml), 배치(LayoutTab.qml), 장식(DecorTab.qml). 여는 법: `apps/rice/studio` 또는 DankBar 의 팔레트 조각.

## 왜 DMS 밖인가

다른 라이싱 축은 "값 하나 고르기"인데 셰이더는 여러 장을 순서대로 쌓고, 조합마다 비용이 곱으로 늘고, 칸마다 손잡이가
따로 있다. 런처의 한 줄짜리 항목 계약에 넣으면 DMS 플러그인이 갈래 이름·탭 곱셈·체인 동사를 전부 알게 되어 "축이
뭔지 모른다"는 자기 계약과 어긋난다. 그래서 별도 창이다. DMS 에 남은 것은 여는 단추와 탈출구(off · 다음 것)다 —
셰이더가 화면을 못 알아보게 만들면 이 창도 같은 유리 뒤에 있기 때문이다([DMS 플러그인](dms-plugins.md)).

## 장식·배치 탭은 예외

**장식**은 "값 하나 고르기"지만 셰이더와 같은 픽셀을 두고 다툰다.
1. 창 자신이 표본이다 — 투명도를 내리면 창도 반투명해져 대비가 어디서 무너지는지 그 자리에서 보인다.
2. 블러 passes 와 셰이더 탭 수가 같은 GPU 를 나눈다.
3. blur:xray 는 셰이더 결과와 겹친다.

둥글기·간격·보더 두께는 DMS 설정 GUI(설정 → 컴포지터 레이아웃, Modules/Settings/CompositorLayoutTab.qml)가 소유하고,
같은 키를 여기서 쓰면 그쪽 슬라이더가 말없이 무효가 되어 뒤판 표에서 뺐다(`apps/rice/decor`). 되돌리기 기준은 하이프랜드
기본값이다.

**배치**는 런처에도 있지만(apps/rice/menu 의 layout 축, 고르기만) 여기에도 둔다.
1. 배치마다 끌어 맞출 값(컬럼 폭, 분할 비율)이 있어 슬라이더 자리가 필요하다.
2. 환경을 바꿀 때(작은 화면에 앉아 dwindle 로 바꾸고 투명도를 올리고 셰이더를 가볍게) 한 창에서 끝나야 한다.

손잡이는 걸린 배치의 것만 보인다. 키바인드는 손잡이가 아니라 파일을 열어 고치고 「다시 읽기」를 누른다(머리 둘째 줄에
파일 경로). 배치 파일 머리말은 서너 줄이라 목록 줄에는 이름과 제목만, 전체 설명은 아래 띠(호버한 것, 없으면 걸린 것;
손잡이 띠와 달리 마지막 것을 안 남긴다). 레포에 없는 파일은 되돌릴 곳이 없다고 줄에 적는다.

## 값은 창에 없다 / 조절하는 화면이 곧 표본

목록, 탭 수, 더할 수 있는 것은 Rice/ 싱글턴이 셸 스크립트에 물어서 가져온다. 곱 한도는 `apps/rice/chain` 만 안다 — 여기서
다시 세면 규칙이 두 벌이 되고 한쪽만 고친 날 목록이 거짓말을 한다. 화면 셰이더는 창을 안 가려서 이 창도 유리 뒤에
그려지므로, 색은 Rice/Theme.qml 한 곳에서만 나온다.

## 목록과 체인

**ShaderList**
- 갈래는 폴더 이름이라 새 폴더면 손 안 대고 는다.
- 줄은 그것 하나만 걸고 `+` 는 체인 뒤에 얹는다(같은 질문, 다른 동작).
- 못 얹는 칸은 빼지 않고 흐리게 두고 이유를 적는다(이유가 곱셈이라 빼면 짐작할 수 없다).
- 설명은 머리말 첫 줄(rice-crt --json 의 blurb)을 아래 띠에 — 체인에 얹을 것은 걸기 전에 읽는다.
- 걸린 줄은 왼쪽 띠로 표시한다. 셰이더를 통과하면 16% 배경 색조만으로는 뭉개진다.
- 포커스 링이 3px 나가므로 여백이 없으면 첫/마지막 줄 링이 잘린다.

**ChainPanel**
- 앞칸 출력이 뒷칸 입력이라 순서가 바뀌면 다른 그림이다(비용은 곱이라 순서와 무관).
- 마지막 한 칸을 빼면 조용히 off.
- 끌기와 화살표를 둘 다 둔다(화살표는 키보드로 닿는 유일한 길이고, 칸이 둘이면 더 빠르다).
- 끄는 동안 rice-crt 를 부르지 않는다 — 중간 순서마다 셰이더가 새로 걸려 번쩍이고 원한 적 없는 조합이 걸린다. 손을 떼면
  applyStages 한 번.
- Column 은 자식 y 를 자기가 정해 끄는 칸을 손이 못 잡아서 Item 에 쌓는다.

**KnobPanel**
- 그룹은 파일 순서(형태 → 광학 → 줄무늬 → 색).
- 대상 칩은 걸린 칸이 번호(apps/rice/knobs 의 pass)와 함께 앞에 온다.
- 가로 스크롤 대신 접는다(가로 스크롤은 잡을 것도 표시도 없어 뒤쪽이 잘린 줄 모른다).
- 설명은 마우스가 지나간 마지막 손잡이 것을 남긴다(띠가 깜빡이면 눈에 걸린다).

**ShaderTab**
- 장식은 DecorTab 이 따로 알고 서로 안 부른다(접점은 shell.qml 의 탭 인덱스).
- 왼쪽은 "무엇을 볼까", 오른쪽은 "지금 것을 어떻게". 체인이 값 쪽에 붙은 건 손잡이 대상 칩이 곧 체인의 칸이라서.
- 저장은 이름이 필요한 유일한 동작이라 누를 때만 펼친다. rice-crt 는 같은 이름을 묻지 않고 덮어쓰므로 치는 동안 단추가
  먼저 알린다. `/` 와 앞점은 못 치게 한다.

**shell.qml**
- 창을 닫아도 FloatingWindow 는 visible = false 일 뿐 ShellRoot 가 계속 돈다. 창 없는 quickshell 이 남으면 바 조각을 눌러도
  apps/rice/studio 의 `-n` 이 "이미 돈다"며 즉시 나가 창이 다시 안 뜨고 로그도 없다. quickshell 0.3.0 에는
  Quickshell.quit() 이 없고 lastWindowClosed 만 있어 Qt.quit() 을 부른다.
- 최소 크기 880×560 은 KnobRow 의 슬라이더가 백 픽셀 아래로 눌리지 않게.
- 토스트는 창 것이고 길이에 비례해 오래 뜬다.
- 탭 전환에 Esc·맨 숫자를 안 쓴다(저장 이름 입력 중에 삼켜지거나 샌다).

## Rice/ 싱글턴

**Shaders**
- `apps/rice/crt --json` 한 번이 다 준다. 곱 한도를 QML 에서 다시 세면 안 된다(런처 플러그인이 `now * taps > (maxTaps ||
  64)` 로 따로 세다 값이 갈렸다).
- 값마다 `apps/rice/chain --info` 를 부르면 열 몇 장에 프로세스 예순 개다. 런처는 2초 캐시로 가렸지만 열어 두고 만지는
  창에서는 못 가린다. 그래서 --json 은 프로세스 하나, 탭·흐름은 mtime 캐시(`apps/rice/chain --info-all`).
- RICE_APPS 는 apps/rice/studio 가 넣고, 없으면 체크아웃 경로다(라이싱 중 스크립트를 자주 고침; `nix run` 일 때만 스토어).
- 밖에서 바뀐 것: Mod+Shift+C·런처 off 로도 바뀌므로, rice-crt 가 걸 때마다 적는 파일(--boot 이 되돌릴 자리)을 FileView
  로 본다. 모르면 ✓ 와 체인이 화면과 다르고, 그때 누른 ＋ 는 옛 체인 위에 얹는다. 내용이 같으면 안 읽는다(rice-knobs
  가 --reload 로 같은 파일을 다시 쓰고, 그때마다 목록을 갈면 끌던 슬라이더가 새로 만들어진다).
- 거절 이유는 stdout(rice_reject)과 stderr(rice-chain 한도 초과) 양쪽에서 와서 모아 마지막 줄을 쓴다. 실패해도 다시
  읽는다(앞 칸만 걸린 중간 상태가 있을 수 있다).

**Knobs**
- 쓰는 곳은 $HOME, 레포는 비교용, 레포에 넣는 건 사람이 판단해서 apps/rice/save 로.
- 한 번 쓰면 파일을 고치고 다시 건다(90ms 쯤). 마지막 값만 모아 보내고, 손을 떼면 타이머 없이 한 번 더.
- 대상 정렬은 걸린 칸을 pass 순으로 앞에. 이 엔진의 sort 는 안정 정렬이 아니라 비교 0 이면 칩이 열 때마다 다른 자리에
  서서, 스크립트 순서로 가른다.
- 셰이더를 갈아도 고르던 것이 목록에 있으면 그대로 둔다.

**Decor**
- 뒤판이 `~/.config/hypr/decor.lua` 를 통째로 다시 쓰고 `hyprctl eval` 로 건다. 하이프랜드 옵션은 범위를 안 알려 줘서 표가
  rice-decor 안에 있다.
- dirty 는 하이프랜드 기본값 기준(decor.lua 는 생성물이라 레포 시드가 없다).
- 디바운스는 Knobs 와 같지만 eval 한 번이라 훨씬 싸다. 다 보낸 뒤에야 다시 읽는다(끄는 중에 목록을 갈면 델리게이트가 새로
  만들어져 손을 놓친다).

**Layouts**
- Shaders 와 Decor 의 중간이다. 손잡이는 걸린 배치의 것만, dirty 는 레포 사본(rice/layouts) 기준.
- 값 하나를 쓰면 배치 파일을 통째로 다시 돌린다(키를 풀고 다시 건다).
- 런처의 배치 축과 `apps/rice/layout --next` 도 같은 파일을 쓰므로 따라간다.
- 시드 전이거나 jq 가 없으면 빈 목록이 "배치가 없다"로 읽히지 않게 이유를 띄운다.

**Theme**
- 별도 프로세스라 `qs.Common` Theme(DMS 루트 모듈에 매인 싱글턴)을 못 가져온다. DMS 는 matugen 팔레트를
  `<캐시>/DankMaterialShell/dms-colors.json` 에 두고 FileView 로 감시한다(Common/Theme.qml 의 dynamicColorsFileView). 같은
  파일을 보면 벽지를 바꾸는 순간 따라가고, 팔레트를 베끼면 그 순간 어긋난다. 밝기 모드는 Common/SessionData.qml 의
  isLightMode. 둘 다 없으면(니리, DMS 없음) 기본값. matugen 이름은 snake_case 라 pick() 에서 한 번 접는다.
- **on\* 이름 함정**: `readonly property color onSurface: pick(...)` 는 같은 객체에 `surface` 가 있으면 시그널 핸들러로
  먹힌다. 바인딩이 사라지고 기본값 검정(#000000)으로 남는데 오류도 경고도 없다(함수 호출은 "실행할 스크립트"로 통과;
  리터럴이면 "Cannot assign a value to a signal"). 형제 속성이 있는 이름만 걸린다 — onSurfaceVariant 는 멀쩡하고
  onSurface·onPrimary 만 검다. 밝은 배경에선 그럴듯해 다크 모드 #101418 위에서만 드러난다. 그래서 DMS 와 같은 `*Text`
  (surfaceText · surfaceVariantText · primaryText)를 쓴다.
- **카드 대비**: matugen 은 surface 와 surface_container 를 같은 값으로 준다(다크 #101418, 라이트 #f7f9ff).
  surface_container_high(다크 #1d2024, HSL 밝기 차 0.049)부터 쓰고 차가 0.035 아래면 한 단 더 든다 — 셰이더를 통과하면
  그보다 좁은 차는 블룸에 먹힌다. 카드 테두리(Ui/Panel)가 유일하게 카드를 가른다.

## Ui/ 부품

- **Btn**: filled(주 동작)·tonal·ghost. 못 누를 때 opacity 대신 잉크만 죽인다(배경 없는 ghost 는 통째로 내리면 어두운
  쪽에서 단추가 사라진다). enabled 를 다시 선언하면 Item 의 것을 가려 부모를 꺼도 이 단추만 눌린다. 호버·누름은 배경
  위에 겹쳐 낸다(투명 배경 ghost 대응).
- **Chip**: 탭과 손잡이 대상 고르기 공용(한 창에 "고르는 것"이 두 모양이면 매번 다시 배운다). 안 고른 칩에도 배경을
  깐다(투명하면 셰이더를 통과하며 칸 경계가 사라진다).
- **DocStrip**: 두 줄 고정(늘면 위 목록이 밀려 손잡이가 커서 밑에서 빠져나간다). 아무것도 안 가리키면 안내.
- **Head**: 12px 글자뿐이라 크기로 위계가 안 서서 색(primary)과 자간으로 가른다(굵기만으로는 셰이더 통과 후 안 갈린다).
- **KnobRow**:
  - 칸 너비 고정(줄이면 줄마다 슬라이더 시작점이 달라진다; 장식은 한 구역에 불리언·실수가 섞인다).
  - 슬라이더 최대 폭 380(0..1 을 창 폭만큼 늘이면 한 픽셀이 눈금보다 잘아진다).
  - 설명은 호버 때 줄 안에서 펴지 않고 패널 아래 띠에(펴면 목록이 마우스 밑에서 튄다), 스위치를 켜면 줄 안에 편다. 띠
    글에는 이름을 붙이고 줄 안 글에는 안 붙인다.
  - 눈금은 범위의 1/100 이라 0.0038 같은 값이 와서 자리 수를 계산하고 최소 한 자리(0 이면 뒤 0 떼기가 "40" 을 "4" 로).
  - dirty 는 색으로 먼저 알리고 되돌리기 단추는 확인.
  - `!motion` 표시는 배터리 값(debug:vfr)이 붙은 손잡이.
- **Scroller**: 목록이 clip 이라 막대가 없으면 넘친 줄이 소리 없이 사라진다. 막대는 넘칠 때만, 끄는 중·호버 때만 진하게.
  Flickable 안의 자식은 내용과 같이 스크롤되므로 Item 으로 싸고 막대를 형제로 둔다.
- **Slide**: Qt Quick Controls 를 안 쓰는 건 DMS 가 박는 QT_QUICK_CONTROLS_STYLE=Material 환경이 별도 프로세스엔 없어서다.
  값은 눈금 인덱스로 굴린다(실수면 0.013999…). 트랙을 누르면 뛰지만 손잡이를 누르면 값을 안 건드리고 끌기만 한다(값이
  누르는 즉시 화면 전체에 걸려 튐이 보인다). 휠은 포커스가 있을 때만(스크롤하다 지나가며 값이 바뀌면 안 된다). 끄는
  동안 밖의 value 는 무시한다(적용이 늦게 돌아와 뒤로 튄다). 손잡이 테두리는 창 배경이 아니라 카드 색(구멍처럼 보임).
  4px 트랙은 위아래로 넓혀 누른다.
- **Toggle**: `checked` 는 밖에서만 바꾼다 — 뒤판이 거절한 값이 화면에만 켜져 있지 않게. 꺼진 쪽에도 테두리와 손잡이
  (트랙 색만으론 카드와 안 갈리고 셰이더가 걸리면 안 보인다).
- **Txt**: DMS StyledText 대신 쓴다. renderType 고정 — 서브픽셀 AA 가 셰이더 색수차와 겹쳐 글자 가장자리에 색이 끼고,
  셰이더 탓인지 렌더링 탓인지 구별이 안 된다.
