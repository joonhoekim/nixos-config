# demo — 창 관리자 실사용 재연

`apps/demo` 는 창 관리자를 실제로 쓰는 모습을 자동으로 재연한다. macOS 에서는 rift-grid(이 저장소의 macOS 타일링 WM),
NixOS 에서는 하이프랜드를 몬다.

```sh
apps/demo                 # 시나리오 목록
apps/demo <시나리오>       # 지금 화면에서 시연
apps/demo <시나리오> --fast | --slow
```

스크린캐스트가 아니라 **진짜 창이 진짜로 움직이는** 시연이다. 녹화본은 낡고 설정은 계속 바뀌므로, 지금 걸린 설정이 지금
어떻게 도는지를 그 자리에서 보여 준다. 스텝마다 키맵의 어느 키인지를 자막으로 띄워, [keymap.md](keymap.md) 를 읽는 것과
화면을 보는 것이 같은 시간에 일어난다. 이미 찍은 영상을 다듬는 것은 짝인 `apps/screencast`
([packages/screencast.md](packages/screencast.md))다.

## 한 파일이 양쪽을 다 안다

자막에 뜨는 키는 양쪽 다 keymap.md 의 것이고(그래서 창 관리자들에 같은 키를 깔았다), 그 아래에서 부르는 것만 갈린다.
시나리오는 플랫폼마다 다르다: DMS 오버레이나 라이싱 프로필은 macOS 에 없고, 레이아웃 모드 넷은 하이프랜드에 없다. 없는
것을 흉내내는 시연은 아무것도 보여 주지 못한다.

## 남의 창을 건드리지 않는다

- 시연은 **빈 워크스페이스**에서만 돈다. 창이 하나라도 있는 워크스페이스는 고르지 않고, 나란히 빈 자리 둘이 없으면 거절한다
  (Mod+Shift+O 로 창을 옆 워크스페이스로 던지는 대목이 있어서 그 옆도 비어야 한다).
- 여는 창은 전부 이 스크립트가 띄운 것이고, 정리는 창을 "닫는" 게 아니라 각 창 안에서 도는 루프에게 나가라고 말하는
  방식이다(`$SENTINEL` 삭제). 그래서 정리 코드가 남의 창을 닫을 경로가 없다 — rift-grid-cli 로 close 를 부르는 곳이 없다.
- 끝나거나 Ctrl+C 를 맞거나 중간에 죽어도 trap 이 같은 정리를 부르고 원래 워크스페이스로 돌려놓는다.

## 키를 누르는 게 아니라 액션을 부른다

자막에는 `Mod+Ctrl+E` 라고 뜨지만 실제로 눌리는 키는 없다. macOS 에서 키 이벤트를 합성하려면 접근성 권한이 필요하고, 그
창이 뜨는 순간 시연이 아니라 사고가 된다. 대신 그 키가 설정에서 부르는 것과 **같은 액션**을 창 관리자에게 직접 넘긴다.
결과는 같고, 키맵과 어긋나면 스크립트가 낡은 것이니 고칠 신호다. 자막의 키 이름과 호출은 두 설정 파일을 옮긴 것이라 그
파일이 바뀌면 같이 바뀌어야 한다:

- macOS: `modules/darwin/rice/rift-grid/config.toml` 의 `[keys]`
- NixOS: `modules/nixos/hyprland/rice/hyprland.lua` 의 키바인드 절

하이프랜드에서 무엇을 부를 수 있는지(그리고 무엇이 `ok` 를 돌려주면서 아무 일도 안 하는지)는
[hyprland-binds.md](hyprland-binds.md). 하이프랜드의 액션은 lua 한 줄이다. `hyprctl dispatch` 에 넘기는 것도 hl.bind 에
적는 표현식 그대로라(hyprland-binds.md 의 "확인하는 법") 시나리오의 문자열은 설정 파일과 글자까지 같다.

## 실측으로 정해진 것들

**배치와 포커스**

- **자막도 타일 창 하나다.** 스크롤링 레이아웃은 띠의 일부만 보여서 컬럼이 셋을 넘으면 자막이 밀려 나간다. 자막 컬럼에
  포커스를 주는 것이 그것을 화면 안으로 끌어오는 유일한 방법이다. float 은 rift-grid 에서 안 된다: 타일로 먼저 들어갔다가
  float 이 되므로 크기가 화면 전체 그대로이고, `window resize-by` 도 XTWINOPS(`ESC[8;rows;cols t`)도 float 창에 먹지 않아
  자막이 배치를 가리거나 뒤로 밀려 안 보인다. 읽는 동안 자막이 앞으로 나왔다가 동작할 때 대상 창으로 넘어가는 리듬 자체가
  스크롤링 레이아웃을 보여 준다.
- **spawn 은 기준창에 먼저 포커스를 준다.** 스크롤링 레이아웃은 새 창을 활성 컬럼 옆에 끼우는데 say() 가 매 스텝 자막
  컬럼으로 포커스를 옮기므로, 그냥 띄우면 새 창이 자막 옆에 쌓여 순서가 뒤집히고 consume 이 오른쪽 이웃을 못 찾고 조용히
  헛돈다.
- **포커스는 방향 탐색이 아니라 창 id 로 준다.** 컬럼이 합쳐지고 갈라지므로 "왼쪽"이 스텝마다 달라지고, 방향 탐색이 자막
  창을 집으면 다음 액션(Mod+Shift+O)이 자막을 옆 워크스페이스로 던진다.
- **follow 를 붙이지 않는다.** 자막 창은 그 워크스페이스에 떠 있어 화면이 넘어가면 따라오지 않는다. 설명이 사라진 채
  배치가 바뀌는 3 초가 시연에서 제일 나쁜 자리라, 창이 빠져나가는 것만 보이고 따라가는 건 다음 스텝에서 한다.
- **워크스페이스 번호**: rift-grid 는 0 부터 세는 고정 아홉 칸(디스플레이마다 한 벌)이라 목록에서 빈 칸을 찾고, 하이프랜드는
  1 부터 세며 창이 없으면 존재하지 않아 "쓰이는 번호"의 여집합을 1..9 에서 찾는다. WS_LABEL 은 사람에게 보이는 번호(둘 다 1 부터).

**터미널 창**

- **macOS 에서 시연 창은 ghostty 가 아니라 wezterm 이다.** macOS 에서 ghostty 를 CLI 로 띄우는 길은 `open -na Ghostty.app
  --args -e <명령>` 하나뿐이고(`ghostty --help` 가 직접 실행은 지원하지 않는다고 말한다), 그 경로로 들어온 명령마다 `Allow
  Ghostty to execute '/tmp/wm-demo.XXXX/alive'? [Cancel] [Allow]` 확인 창을 띄운다. LaunchServices 로 임의 명령이 주입되는
  걸 막는 장치라 끌 설정도 없다. 창 넷을 여는 시연은 확인 창을 넷 맞고 그 사이 배치가 엉킨다. wezterm 은 바이너리를 그냥
  실행할 수 있다. 리눅스에는 이 제약이 없어 ghostty 를 부른다.
- **창 제목은 이스케이프 시퀀스로 세운다.** 터미널의 --title 류 옵션은 -e 로 준 명령이 덮어쓴다. rift-grid 가 이 제목을 창
  목록에 쓰므로(`rift-grid-cli query windows`) 시연이 헤맬 때 밖에서 어느 창인지 보인다.

**환경**

- **화면을 얼리는 레이어가 남아 있으면 헛돈다.** hyprpicker(hyprshot -z 가 띄운다)나 slurp 이 키보드 포커스를 쥐고 있으면
  `focus` 가 `ok` 를 돌려주면서 활성 창이 없는 상태가 되고, 모든 액션이 대상을 못 찾는다.
- **ssh 로 들어와서 부를 수 있어야 한다.** 세션 밖에서는 세션 환경 변수 셋이 비어 hyprctl 은 "no instance", ghostty 는 "no
  wayland compositor" 로 죽는다.

**하이프랜드 쪽**

- **상태를 보고 뒤집히는 액션이 없다.** rift-grid 와 niri 에는 있지만, hyprland.lua 의 Mod+Ctrl+E 는 컬럼의 형제 수를 세어
  consume 과 promote 중 하나를 고르는 함수다. 시연은 어느 쪽인지 알므로 둘을 직접 부른다. expel 은 포커스와 상관없이 컬럼
  맨 아래 창을 뱉으므로 골라 빼는 것은 promote 다.
- **DMS 오버레이는 open/close 짝으로 부른다.** 오버레이는 레이어라 워크스페이스에 속하지 않는다. toggle 은 지금 상태에
  기대는데 시작할 때 상태를 알 수 없다 — 누가 치트시트를 켜 둔 채 부르면 첫 스텝이 그걸 끄고 이후 오버레이가 한 칸씩
  어긋난다. `dms ipc` 는 짝(open/close, openOverview/closeOverview, hide)을 다 갖고 있다. 열어 둔 채 넘어가면 스포트라이트처럼
  키보드를 통째로 잡는 것이 뒤를 막는다.
- **치트시트만 창이다.** 오버뷰·알림·컨트롤센터·스포트라이트는 layer-shell 이지만 치트시트는 quickshell 이 보통 창으로 띄우고
  하이프랜드가 타일링한다. 컬럼이 셋이면 넷째로 들어가 화면 밖에 열린다. 열고 나서 그 창으로 포커스를 옮기면 띠가 스크롤해 온다.
